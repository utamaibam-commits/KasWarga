Pasang KasWarga di Perangkat Anda

Buka link aplikasi KasWarga dari halaman pembelian Lynk.id, lalu pasang ikonnya. Tidak perlu aplikasi tambahan dan gratis. Setelah dibuka sekali, KasWarga jalan tanpa internet.
  1. Buka link KasWarga di Chrome

    Kalau link terbuka di WhatsApp/Instagram, ketuk menu ⋮ lalu pilih Buka di Chrome.

  2. Ketuk menu ⋮ di pojok kanan atas

    Pilih Instal aplikasi atau Tambahkan ke Layar utama.

  3. Ketuk Instal / Tambahkan

    Ikon KasWarga muncul di layar HP seperti aplikasi biasa.

  4. Selalu buka dari ikon itu

    Data tersimpan di HP ini dan bisa dipakai tanpa kuota.

  1. Buka link KasWarga di Safari

    Harus Safari (ikon kompas biru). Kalau terbuka di WhatsApp/Instagram, pilih Buka di Safari.

  2. Ketuk tombol Bagikan

    Ikon kotak dengan panah ke atas, di bawah layar (iPad: di atas).

  3. Pilih "Tambah ke Layar Utama"

    Geser daftar ke bawah, ketuk Tambah ke Layar Utama lalu Tambah.

  4. Buka dari ikon KasWarga

    Di iPhone, data di ikon dan di Safari terpisah. Selalu pakai ikon yang sama.

  1. Buka link KasWarga di Chrome atau Edge

    Bisa di laptop Windows, Mac, atau Chromebook.

  2. Klik ikon pasang di kolom alamat

    Ikon layar dengan panah di ujung kanan kolom alamat, atau menu ⋮ lalu Instal KasWarga / Aplikasi → Instal situs ini.

  3. Buka dari Start Menu / Dock / Desktop

    KasWarga terbuka di jendela sendiri. Cocok untuk mencetak laporan ke printer atau simpan PDF.

Data tersimpan di perangkat ini saja. Jangan hapus "data situs/riwayat" browser, dan lakukan Backup rutin dari menu Pengaturan. Mau pindah ke HP lain? Backup di HP lama, lalu Restore di HP baru.

Cara Pakai 5 Menit

  1. Isi nama grup & jenis iuran

    Pengaturan: nama RT/arisan/kelas, nama bendahara, cara bayar, dan iuran (misal Iuran Kas Rp20.000/bulan).

  2. Masukkan daftar warga

    Menu Data Warga, pakai Tambah Banyak Sekaligus: tempel daftar nama dari grup WA, satu nama per baris.

  3. Centang yang sudah bayar

    Menu Iuran: ketuk tombol centang di samping nama. Bayar beberapa bulan sekaligus juga bisa.

  4. Kirim rekap ke grup WA

    Tombol Kirim ke WA menyusun daftar sudah/belum bayar otomatis. Teksnya bisa diedit dulu sebelum dikirim.

  5. Catat pengeluaran & cetak laporan

    Buku Kas untuk pengeluaran. Laporan bisa dicetak/disimpan PDF untuk rapat warga.

Pertanyaan Umum

Apakah butuh internet?

Hanya saat pertama membuka link dan memasang ikon. Setelah itu semua jalan di perangkat Anda tanpa kuota. Internet dipakai lagi hanya saat Anda menekan tombol kirim ke WhatsApp.

Datanya disimpan di mana? Aman?

Di penyimpanan browser perangkat ini. Data warga dan keuangan tidak dikirim ke server mana pun. Karena itu, jangan hapus data situs browser dan lakukan Backup rutin.

Bisa dipakai untuk arisan atau kas kelas?

Bisa. Di Pengaturan pilih jenis grup (RT/RW, Arisan, Kas Kelas, Komunitas). Sebutan "Warga" otomatis berubah menjadi Anggota/Siswa.

Warga bayar 3 bulan sekaligus, bagaimana?

Ketuk nama warga di menu Iuran, pilih "Bayar untuk 3 bulan". Bulan yang belum lunas akan terisi otomatis berurutan.

Uang arisan masuk ke kas RT?

Tidak. Arisan dicatat terpisah, karena uangnya langsung diberikan ke pemenang. Saldo kas hanya berisi iuran dan pemasukan/pengeluaran di Buku Kas.

Bendahara ganti, datanya bagaimana?

Bendahara lama: Pengaturan → Backup Data, kirim file .json ke bendahara baru. Bendahara baru: buka KasWarga → Pengaturan → Restore Data.
